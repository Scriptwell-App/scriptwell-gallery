# Bluesky Stats

Followers and posts for any Bluesky account, with the change since yesterday.

- **Type:** Widget, Mini-app, Shortcuts action
- **Widget sizes:** small, medium
- **Permissions:** `network` to fetch data over HTTPS

## Notes

Put a handle such as "bsky.app" in the widget's Parameter field, or set one in the app. Uses Bluesky's public API: no login and no key.
