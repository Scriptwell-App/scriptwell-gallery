# Next F1 Race

Countdown to the next Formula 1 Grand Prix, with qualifying and sprint times in your time zone.

- **Type:** Widget, Mini-app, Shortcuts action
- **Widget sizes:** small, medium, rectangular, inline
- **Permissions:** `network` to fetch data over HTTPS

## Notes

The calendar comes from the community-run Jolpica F1 API (free, no key). Unofficial: not associated with Formula 1 or the FIA.
