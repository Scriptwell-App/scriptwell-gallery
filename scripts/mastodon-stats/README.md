# Mastodon Stats

Followers and posts for any Mastodon account, with the change since yesterday.

- **Type:** Widget, Mini-app, Shortcuts action
- **Widget sizes:** small, medium
- **Permissions:** `network` to fetch data over HTTPS

## Notes

Put an address such as "Mastodon@mastodon.social" in the widget's Parameter field, or set one in the app. Uses the server's public API: no login.
