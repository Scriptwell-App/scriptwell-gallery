# Unit Price

Which pack is the better deal? Compare prices by weight, volume or count.

- **Type:** Mini-app, Shortcuts action
- **Permissions:** none

## Notes

Enter the price and the amount for each pack, for example "2.49 500" for 2.49 for 500 g. The amounts only need to be in the same unit as each other. From Shortcuts: "2.49/500 3.99/1000".
