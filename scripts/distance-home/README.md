# Distance Home

How far you are from home and which way it is, at a glance.

- **Type:** Widget, Mini-app, Shortcuts action
- **Widget sizes:** small, medium, circular, inline
- **Permissions:** `location` to read your current location

## Notes

Open the script once at home and tap "I am home now". After that the widget shows the straight-line distance and the compass direction back. Your location stays on the device: this script has no network permission.
