# Hacker News Top

The top stories on Hacker News, on your Home Screen and in a reader list.

- **Type:** Widget, Mini-app, Shortcuts action
- **Widget sizes:** medium, large
- **Permissions:** `network` to fetch data over HTTPS

## Notes

Stories come from the official Hacker News API (free, no key). The last list is kept, so the widget still shows something when you are offline.
