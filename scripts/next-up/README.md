# Next Up

Your next calendar events, with a live countdown to the one that starts soonest.

- **Type:** Widget, Mini-app, Shortcuts action
- **Widget sizes:** small, medium, rectangular, inline
- **Permissions:** `calendar` to read your calendar events

## Notes

Reads your calendars on the device; nothing leaves it (this script has no network permission). All-day events are left out of the countdown.
